# KNR Sportverse Android App
WebView app for https://knrsportverse.blogspot.com with animated splash, in-app link handling,
pull-to-refresh, progress bar, offline screen.

## Get the APK (no Android Studio needed)
1. Create a free GitHub repo, upload this folder's contents (keep the .github folder).
2. Open the repo > Actions > "Build KNR Sportverse APK" > Run workflow.
3. After ~3 min: download from Actions > Artifacts, or from the repo's Releases page (direct .apk link).

## Or build locally
Open in Android Studio and press Build > Build APK, or run: gradle assembleDebug
